# Contributing

Tutte le contribuzioni, segnalazioni di bug, correzioni di bug, miglioramenti della documentazione, potenziamenti e idee sono benvenuti.

All contributions, bug reports, bug fixes, documentation improvements, enhancements and ideas are welcome.

## Come contribuire

1. Fai il fork del repository.
2. Crea un nuovo branch per la tua modifica (`git checkout -b my-feature`).
3. Applica le modifiche e committale con un messaggio chiaro.
4. Fai il push del branch sul tuo fork (`git push origin my-feature`).
5. Apri una pull request verso il branch `main` di questo repository.

## Segnalazioni di bug

Quando segnali un bug, includi:

- una breve descrizione del problema
- i passaggi per riprodurlo
- cosa ti aspettavi e cosa è successo invece

## Miglioramenti della documentazione

Correzioni di refusi, formulazioni poco chiare o spiegazioni mancanti sono benvenute quanto le modifiche al codice.

## Codice di condotta
