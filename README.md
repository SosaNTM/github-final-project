# github-final-project

## Simple Interest Calculator

A calculator that calculates simple interest given principal, annual rate of interest and time period in years.

Calcolatore di interesse semplice che calcola l'interesse a partire da capitale, tasso di interesse annuo e periodo di tempo in anni.

## Formula

Simple Interest = (P x R x T) / 100

- P (principal): capitale, la somma di denaro investita o prestata
- R (rate of interest): tasso di interesse annuo in percentuale
- T (time period): periodo di tempo in anni

## Input fields

Lo script simple-interest.sh chiede all'utente tre valori in input:

1. principal, il capitale
2. rate of interest, il tasso di interesse
3. time period, il periodo di tempo in anni

## Output

Lo script stampa a schermo l'interesse semplice calcolato e il totale finale.

## Usage

Eseguire lo script con: bash simple-interest.sh
